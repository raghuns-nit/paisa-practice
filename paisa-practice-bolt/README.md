# Paisa Practice — expanded Bolt-ready finance learning mock

A mobile-friendly family financial literacy simulator for India. Every bank, insurance provider, stock, fund, account, payment and rupee is fictional. **Sandbox. No real money.**

## Start

1. Import repository files into Bolt.new (or upload to GitHub and import repository).
2. Run `npm install` and `npm run dev`.
3. Run `npm run build` and `npm test` (not verified in the authoring environment because dependency installation timed out).
4. Open `docs/BOLT_NEXT_PROMPT.md` and paste the instructions into Bolt to refine and deploy.

## Built modules
Demo home dashboard, family profiles, Demo Bank and payment labs (UPI/ATM/cheque), Post Office RD/PPF/TD/MIS/SSY concepts, bonds & yield demo, fictional insurance claims, demat/funds and scheduled SIPs, statements, search, tax-tag education, security lesson, quiz, JSON backup and reset. LocalStorage saves state in this browser only. Financial calculations beyond the event-ledger scope are illustrative.

## Scope and limitations
Read `docs/IMPLEMENTATION_STATUS.md` for explicit feature-by-feature coverage and limitations. This is a mock classroom product; do not use real credentials, identification details, or actual money. Supabase and genuine authentication have deliberately been deferred.
